# Chilly — Desktop Fridge

A frameless, transparent Electron refrigerator toy for the Windows desktop.

## Run

```powershell
npm install
npm start
```

## Play

- Click the refrigerator door to open it and turn on the light.
- Drag drinks out of the door racks and arrange them around the fridge.
- Click the bottom vegetable drawer to open and close it.
- The main door cannot close while the vegetable drawer is open.
- When the main door is closed, hold and drag the fridge to move its window around the desktop.
- Use the small `×` button at the top-right of the fridge to quit.
